## 🚀 Quick Start (You'll Be Running in 5 Minutes!)

### Prerequisites Checklist
- [ ] Node.js installed
- [ ] Stripe account created (free)
- [ ] MongoDB installed or Atlas account

### 3-Step Setup
```bash
# 1. Get Stripe Keys from https://stripe.com
#    (Dashboard → API Keys → Copy test keys)

# 2. Backend
cd backend
npm install
# Edit .env with MongoDB URI and Stripe keys
npm run seed
npm run dev

# 3. Frontend (new terminal)
cd frontend
npm install
# Edit .env with Stripe key
npm start

# 🎉 Open http://localhost:3000
```

**See `SETUP_INSTRUCTIONS.md` for detailed step-by-step guide!**
